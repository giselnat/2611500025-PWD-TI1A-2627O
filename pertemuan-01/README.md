# pertemuan-01
1. Menurut saya, konsep dasar pemrograman web adalah proses membuat aplikasi atau halaman yang berjalan melalui internet menggunakan HTML sebagai struktur, CSS sebagai tampilan, Java Script sebagai media interaksi, dan juga biasanya melibatkan client dan server yang saling bertukar data. <br>
2. Arsitektur Klien-Peladen adalah sistem dimana klien mengirim permintaan kepada peladen, kemudian server memproses permintaan dan mengirimkan kembali data kepada klien.<br>
3. HTTP Request dan response adalah proses komunikasi antara klien dan server. HTTP Request adalah permintaan yang dikirim klien ke server. HTTP Response adalah jawaban dari server yang dikirim kembali ke klien.<br>
4. -HTML adalah membuat struktur dan isi halaman web.
-CSS mengatur tampilan dan desain halaman web.
-Java Script menambahkan interaksi dan fitur dinamus pada halaman web.
-PHP adalah bahasa pemrograman sisi server untuk memproses data dan membuat web dinamis.
-MySQL adalah sistem basis data untuk menyimpan dan mengelola data pada aplikasi web.<br>
5. Hubungan antarteknologi adalah kerja sama antara berbagai teknologi dalam membuat sebuah aplikasi web.
